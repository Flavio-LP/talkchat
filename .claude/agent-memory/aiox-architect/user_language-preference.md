Flavio writes prompts and project specs in Brazilian Portuguese, and expects
delivered artifacts (architecture docs, plans, summaries) in Portuguese too,
with English kept for technical terms, code identifiers and API field names.

Observed on the Chalk Talk project: `prompt-claude-code-chalk-talk.md` and
`chalk-talk-plan.md` are both pt-BR; the architecture doc was delivered in
pt-BR and accepted.

**How to apply:** Default to Portuguese for prose in docs and final summaries
in this repo. Do not translate code, config keys, model IDs, or HTTP/API
vocabulary. Related: [[project-chalk-talk]]
